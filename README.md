# Material Manager
Little app that allows you to display the items in the material list. It should also, eventually, be possible to
print the barcodes directly from there (interesting challenge since it's a bit of a non-standard printer).

First step: Have a list

Second step: Display the EAN13 barcode (will be useful to test the material-inout-desktop-v2 features)

Third step: Write back to the Excel file with track change and new EAN code.

Fourth step: Link to the official material list / fill out that Excel file? Checklist for the different material.
